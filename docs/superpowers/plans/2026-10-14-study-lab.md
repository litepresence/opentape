# Study Lab + Unlimited Drawings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full user control over every indicator parameter, multiple plotted instances per study (e.g. SMA mesh), in one modular modal matching page style; drawing tools stay selected for unlimited placements with Escape exit.

**Architecture:** `state.studies` migrates from `string[]` to instance objects `{uid, id, params, color, visible}`; registry gains per-study `params` definitions; one modal replaces the indicators dialog content; chart renders instances (full-history compute, window by slice); drawings keep persistent tool + pending preview + Escape.

**Tech Stack:** Vanilla ESM + DOM, no new deps. Native `<input type=number/color>` controls.

## Global Constraints

- Vanilla only: no frameworks, no chart libs. No new npm dependencies.
- All state mutations go through ViewState then `requestRender()`. No direct canvas writes from UI handlers.
- Tooling scripts live in `tooling/` only.
- Modal matches page style: TrebuchetMS font stack, `--text #0f0f0f`, chrome `#ebebeb`, works in light + dark via CSS vars.
- Backward compat: legacy `studies: string[]` layouts and Task-7 `indicators: {sma20,sma50,ema20,rsi}` flags migrate to instances on load; nothing silently dropped.
- GET-only public data; no secrets.

**Interfaces:**
- Consumes: `STUDIES`, `computeStudy(id, rows, opts)` (unchanged signature)
- Produces: `makeInstance(id, overrides)` → `{uid, id, params, color, visible}`; `migrateStudies(raw)` → instance array from `string[] | {legacy flags} | instance[]`; chart reads `state.studies` as instances (tolerates legacy ids read-only, never writes legacy).

Param-def inference rules (apply per study by reading its vendor `_per`/opts handling; every `opts` key gets exactly one def and vice versa):
- period-like keys (`period`,`kPeriod`,`dPeriod`,`kSlowing`,`short`,`medium`,`middle`,`long`,`fast`,`slow`,`tenkan`,`kijun`,`senkouB`,`r1`,`r2`,`r3`,`r4`,`sig`,`k`,`d`,`span`,`avg`,`atr`,`ema`,`min`,`max` when integer-count, `displacement`): `{type:'int', min:1, max:500, step:1}` except `displacement` `{type:'int', min:-100, max:100, step:1}` and keltner `atr`/`ema` (periods, int ≥1).
- float keys (`stddev` {min:0.1,max:5,step:0.1}, `mult` {min:0.1,max:5,step:0.1}, `deviation` {min:0.1,max:20,step:0.1}, `brickPercent` {min:0.1,max:10,step:0.1}, `alpha` {min:0.01,max:1,step:0.01}, `beta` {min:0,max:1,step:0.01}, psar `step` {min:0.001,max:0.2,step:0.001}, psar `max` {min:0.01,max:1,step:0.01}, supertrend `top`/`bottom` {min:0.5,max:10,step:0.5}, frama `fractalPeriod` {min:1,max:10,step:1} — verify each against the vendor fn, fix values that are wrong).
- Studies with `opts:{}` / `arg:'none'` get `params:[]` (no editors, still multi-instanceable).
- Colors: instance `color:null` → palette by registry index (`stuColor`); explicit color overrides. `visible:false` skips render but keeps the instance.

```js
// tests/study-instances.test.mjs
import test from 'node:test';
import assert from 'node:assert/strict';
import { STUDIES, makeInstance, migrateStudies } from '../js/studies.js';

test('every opts key has exactly one param def and vice versa', () => {
  for (const s of STUDIES) {
    const optKeys = Object.keys(s.opts || {}).sort();
    const parKeys = (s.params || []).map(p => p.key).sort();
    assert.deepEqual(parKeys, optKeys, s.id);
    for (const p of s.params || []) assert.ok(['int', 'float'].includes(p.type), s.id + '.' + p.key);
  }
});
test('sma period actually changes output', async () => {
  const { computeStudy } = await import('../js/studies.js');
  const rows = Array.from({ length: 60 }, (_, i) => ({ o: 1, h: 2, l: 0.5, c: 100 + i, v: 1 }));
  const a = computeStudy('sma', rows, { period: 5 }).series.line;
  const b = computeStudy('sma', rows, { period: 50 }).series.line;
  assert.notDeepEqual(a, b);
});
test('migrateStudies converts legacy forms', () => {
  const fromIds = migrateStudies(['sma', 'rsi']);
  assert.equal(fromIds.length, 2);
  assert.ok(fromIds.every(i => i.uid && i.params && 'color' in i));
  const fromFlags = migrateStudies({ indicators: { sma20: true, rsi: true } });
  const sma = fromFlags.find(i => i.id === 'sma');
  assert.equal(sma.params.period, 20);
});
```
